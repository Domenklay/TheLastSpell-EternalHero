# Eternal Hero — Вечный защитник для The Last Spell

## v0.15 — собственные навыки из оружия и украшений

**Отказ от экспериментальных XML-навыков.** Предыдущие 7 самодельных определений не загружались в игре (0/7 в диагностике TLS.ModKit), поэтому обученные способности не попадали на боевую панель.

Вместо них меню **Техники** открывает новый **Арсенал героя**:
- Программа извлекает настоящие способности из `ItemDatabase.AllItemsDefinitions[*].SkillsByLevel` и `SkillDatabase.SkillDefinitions`. Учитываются только категории ближнего, стрелкового, магического оружия и украшений.
- Выбранное умение покупается **навсегда за 4 эссенции**, сохраняется в `HeroProfile.PermanentVanillaSkills` и автоматически выдаётся герою после создания нового забега или загрузки сохранения.
- Техника создаётся штатным `SkillController` со **SkillContainer = герой** и добавляется в `NativeSkills`. Предмета нет — **инвентарь, украшения и слоты оружия остаются свободными**. Боевой интерфейс должен показывать умения на стандартной панели героя, без отдельного окна.
- Каталог содержит поиск, фильтры «Ближний бой», «Стрельба», «Магия», «Украшения», «Купленные», и непрерывную прокрутку.
- Лимит — до 40 приобретённых навыков (заведомо сильнее стандартного героя).
- Старые узлы «Запретные техники / Триединство» сохранены для истории прокачки, но **больше не выдают экспериментальные XML-навыки**. Доступ к ним через кнопку «УЗЛЫ ТЕХНИК». За прежние купленные базовые узлы начисляется однократная компенсация **5 эссенций за каждый**, чтобы их можно было потратить в новом арсенале.
- **TLS.ModKit больше не обязателен** для оригинальных умений. Старые XML-патчи не включены в установочный архив; при переходе с прежних версий рекомендуется удалить только старую папку `BepInEx/plugins/EternalHero/ModKit/Skills`.

### Постоянные игровые перки

Профиль с выбранными перками сохранён. Выдача теперь дополнительно пишет реальные ошибки из `PerkController.Unlock` в журнал и в состояние перка по наведению в меню. Если «Точные удары» всё ещё отмечены «НЕ ВЫДАН», причиной может быть отказ игрового API, а не отсутствие случайного значка в дереве; не утверждаем, что исправили конкретный отказ до тестирования в игре.

### Проверка

Автоматически проверено: компиляция DLL, тесты расходов и компенсации эссенции, статическая проверка чтения исходных определений оружия/украшений. **Фактическое использование оригинальных умений без предмета и активация некоторых условных перков требуют проверки в The Last Spell.** Часть штатных навыков может иметь собственные условия применения, связанные с классом предмета или ситуацией.
