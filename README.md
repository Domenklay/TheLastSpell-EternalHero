## v0.18 — урон оружейных навыков и выдача постоянных перков

### Исправлено: «Картечь» и другие оружейные умения с нулевым уроном

У The Last Spell базовый урон оружейного навыка берётся из `AttackSkillAction.BaseDamage`: если в определении навыка нет своей формулы, игра ищет `SkillContainer` типа `Item`. У купленных через наш арсенал навыков контейнер — сам ГГ, поэтому игра возвращала `Vector2.zero`.

Теперь Harmony-патч `AttackSkillAction.BaseDamage` для **только наших купленных и включённых** навыков подставляет реальный исходный базовый урон из `ItemDefinition.BaseDamageByLevel`. Игра затем рассчитывает процент навыка (например, у «Картечи» — 75%), характеристики, крит, эффекты и сопротивление обычным способом. Выбирается максимальное доступное исходное значение из игровых предметов, предоставляющих этот навык. **Оружие не выдаётся и слоты не занимаются.** Никакие другие герои и обычные навыки не изменяются.

В `BepInEx/LogOutput.log` появляется строка `native item skill base damage adapter installed`. При отсутствии исходных значений выводится `no source weapon damage`, чтобы не скрывать проблему.

### Исправлено: постоянные перки, отсутствующие в случайном дереве

Ранее мод требовал точно семипараметрический публичный конструктор `PerkController`. На установленной версии игры проверка не проходила, о чём появлялось сообщение «Конструктор штатного PerkController недоступен» / «Неподдерживаемая версия».

Новый механизм:
- Находит настоящий тип контроллера среди **уже работающих перков этого же героя**, при необходимости ищет игровой `PerkController`.
- Проверяет доступные публичные и непубличные конструкторы, сопоставляет параметры определения перка, владельца, маркеров native/fromRace и других аргументов.
- Создаёт объект, регистрирует его через `PlayableUnitPerksController.TryAddPerk` и разблокирует штатным `PerkController.Unlock(hero)`.
- Для ручной покупки перков за очки забега используется тот же механизм.
- Если подходящего конструктора нет, сообщает реальные сигнатуры, тип определения и тип героя в журнале и в диагностике, не выдавая ложного успеха.
- Сохранён автоматический повтор после загрузки и кнопка **«ПРИМЕНИТЬ ПЕРКИ»**.

Работающий арсенал, иконки, переключатели навыков, валюта, расы, персонаж и ранее сделанные покупки сохраняются.

**Статус:** код компилируется, автоматические тесты ядра и проверки интеграции проходят. Боевые расчёты и совместимость с конкретной версией клиента The Last Spell требуют проверки в самой игре.
