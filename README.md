# Eternal Hero — Вечный защитник для The Last Spell

[![CI](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml/badge.svg)](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml)

## v0.10 — полностью переработанный каталог черт

После v0.9 огромный список черт/перков требовал десятков страниц. **Переключения страниц больше нет**.

### Новый интерфейс

- **Поиск в процессе ввода**: название, ID, эффект, специализация; несколько слов одновременно (например, «яд урон»).
- **8 категорий черт**: Все, Урон, Защита, Здоровье, Мана, Подвижность, Точность, Особые. Смешанная черта доступна в каждой подходящей категории.
- **Быстрые фильтры**: Все / Без штрафов / Со штрафами / Выбранные / Доступные.
- **4 колонки и непрерывная прокрутка** колёсиком мыши. Кнопки «Следующая страница» и «Предыдущая страница» удалены.
- **Виртуализированная выдача**: Unity создаёт только карточки нескольких видимых рядов, а не тысячи кнопок одновременно.
- **Выбранные черты закреплены под портретом**: видны первые названия и количество; кнопка «СПИСОК» одним нажатием показывает только выбранное.
- **Подробный просмотр** через «?» у любой черты. Отдельное окно с полным текстом эффектов; длинное описание прокручивается. Описание черты получается из штатного `UnitTraitDefinition.GetDescription()`, с игровой локализацией.
- **Сохранение позиции**: при выборе/снятии черты интерфейс остаётся на том же участке списка. При новой категории или новом поиске прокрутка возвращается к началу.
- Выбор постоянных перков и перков текущего забега работает в этом же интерфейсе. Каталог перков сохраняет игровые иконки, категории и уровни.

### Сохранения и ограничения

Это **обновление интерфейса**. Не изменены: до 12 дополнительных постоянных черт, 96 узлов развития, личные достижения, метаэссенция, расовые бонусы, постоянные и разовые перки. Используется существующий профиль `BepInEx/config/EternalHero/profile.json`.

**Проверено CI:** сборка DLL, тесты системы прогрессии и классификации эффектов, XML специальных умений. **Не проверено в запущенной игре:** работа прокрутки и размеры окна на разных разрешениях — требуется визуальная проверка.
