# Eternal Hero v0.18 — установка и проверка

1. Сделай резервную копию игры/сохранений и `BepInEx/config/EternalHero/profile.json`.
2. На [странице сборок GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml) выбери последний успешный запуск и скачай артефакт `EternalHero-v0.18`.
3. Скачанный ZIP распакуй **один раз в корень The Last Spell**, с заменой файлов в `BepInEx/plugins/EternalHero`. Вложенного ZIP нет. Не удаляй файл с накопленной метапрокачкой.
4. Запусти тот же забег, которым проверял «Картечь». Вкладка «Техники → Арсенал героя» сохраняет предыдущие покупки и состояния «ВКЛ.»/«ОТКЛ.».
5. Выбери «Картечь» и посмотри всплывающий урон: вместо нуля должен использоваться диапазон базового урона настоящего предмета из игровой базы, а затем штатные множители урона. Проверь реальную атаку по противнику. Никакого оружия надевать не нужно.
6. Открой **«Черты → Перки → Постоянные»** и нажми **«ПРИМЕНИТЬ ПЕРКИ»**. Для перков вне случайных колонок, включая «Точные удары» и «Любовь к обучению», ожидается переход к статусу **ВЫДАН** без расхода дополнительных очков.
7. Отдельно проверь условный эффект «Точных ударов» (убийство врага с полного здоровья и с расстояния не менее пяти клеток). Не делай вывод только по серому значку в оригинальном дереве.
8. Перезагрузи сохранение и проверь, что купленные и отключённые навыки остаются в профиле, а выбранные постоянные перки восстанавливаются.

### Если эффект остаётся неправильным

После этих действий пришли `BepInEx/LogOutput.log` и скрин результата. Полезные строки:
- `native item skill base damage adapter installed` или `no source weapon damage`
- `native off-tree perk factory` (показывает подобранный конструктор)
- `Eternal Hero permanent perk ACTIVE`
- `Не удалось создать штатный PerkController` / `Off-tree perk constructor rejected`

Важное ограничение: успешная компиляция подтверждает синтаксис и наличие зависимостей, но не доказывает работу игры. Часть исходных атак может иметь дополнительные требования к оружию, не связанные с базовым уроном.
