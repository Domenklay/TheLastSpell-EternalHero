# Eternal Hero v0.10 — установка и проверка интерфейса черт

Перед установкой **сохрани копию** `BepInEx/config/EternalHero/profile.json` и игровые сохранения.

1. BepInEx 5 и TLS.ModKit оставь установленными как раньше.
2. Открой [GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml), выбери последний успешный запуск и скачай артефакт **EternalHero-v0.10**.
3. Открой внешний ZIP и распакуй **EternalHero-v0.10.zip** в корневую папку игры с заменой. Проверь, что нет второй копии `EternalHero.Plugin.dll`.
4. Открой меню ГГ клавишами F8/F9/Home либо кнопкой ✦ справа на экране. Перейди в **Черты**.
5. Используй одну из категорий **Урон / Защита / Здоровье / Мана / Подвижность / Точность / Особые**. Число после названия категории показывает число черт данного типа.
6. Введи в поиске несколько слов, например **«critical damage»** или часть русского названия черты. Результаты меняются без подтверждения клавишей Enter.
7. Прокручивай единый список мышью. Нет страницы 2/99 и кнопок пагинации.
8. Выбери любую черту в середине списка: позиция прокрутки должна сохраниться, а **Выбрано черт** под портретом — обновиться.
9. В левой панели нажми **СПИСОК**: каталог покажет только выбранные. Нажми кнопку **ВСЕ**, чтобы вернуться ко всему списку.
10. Нажми **?** у любой карточки. Должно появиться отдельное окно с полным описанием и прокруткой для длинных эффектов. Закрой его крестиком.
11. Переключись в **Перки**: режимы **Постоянные / В забеге** работают по старым правилам, но теперь также без пагинации.

**Важно:** мод не снимает ограничения оригинального отображения черт: в обычной карточке игры по-прежнему видно ограниченное число иконок. Выбранные дополнительные черты остаются в профиле и доступны в модовом каталоге.

Если список пуст после запуска, сначала открой забег: игровая база черт может загружаться не на главном экране. Если окно пропускает клики, теряет прокрутку или отображает некорректные символы, пришли скриншот и `BepInEx/LogOutput.log`.

Настройка размеров: `BepInEx/config/domenklay.tls.eternalhero.cfg`, параметр `MenuScale = 0.78`. Другие настройки v0.9 сохранены.
