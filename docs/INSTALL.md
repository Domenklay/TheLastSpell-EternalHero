# Eternal Hero v0.17 — установка и проверка

1. Сначала сохрани копию игровых сохранений и `BepInEx/config/EternalHero/profile.json`.
2. Скачай артефакт **EternalHero-v0.17** со страницы [GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml) (последний зелёный запуск).
3. Распакуй скачанный ZIP **один раз** в корень игры. Внутри сразу папка `BepInEx/` и `INSTALL.md`. Согласись на замену двух DLL; BepInEx 5 должен оставаться установленным.
4. Открой **Техники → Арсенал героя**. У навыков должны быть оригинальные иконки из игры.
5. На купленной способности нажми **«ОТКЛЮЧИТЬ»**. В строке появится статус «ОТКЛ.»; в бою у Вечного защитника эта дополнительная способность должна исчезнуть. Покупка остаётся, баланс эссенции не уменьшается.
6. Нажми **«ВКЛЮЧИТЬ»**. Навык должен снова появиться на панели. После перезапуска игры, загрузки и нового забега переключатель должен сохранить своё состояние.
7. В **Черты → Перки → Постоянные** нажми **«ПРИМЕНИТЬ ПЕРКИ»**. Проверь, стал ли ранее невыданный перк «Точные удары» активным. Если нет, открой описание по кнопке **«?»** или наведи мышь — будет выведена причина ошибки, если игровой API её сообщил.

**Примечание:** кнопки переключают только дополнительные навыки из нашего арсенала. Другие персонажи и экипировка остаются без изменений. У некоторых оригинальных умений могут быть собственные игровые требования к оружию; появление кнопки не гарантирует срабатывания особой атаки без нужного предмета.

### Если что-то не работает

Пришли `BepInEx/LogOutput.log` после нажатия и снимок панели. Для навыков в логе ищи `Eternal Hero: skill disabled from NativeSkills` и `Eternal Hero stock native skill granted`. Для перков — `Eternal Hero permanent perk ACTIVE` или `Eternal Hero permanent perk` с причиной отказа.

Для арсенала TLS.ModKit больше не требуется. Старые XML-файлы мода из `BepInEx/plugins/EternalHero/ModKit/Skills` можно удалить, если они остались от прежних выпусков.
