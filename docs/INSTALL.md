# Eternal Hero v0.20 — установка и проверка

1. Сохрани копию игровых сохранений и `BepInEx/config/EternalHero/profile.json`.
2. Скачай ZIP-артефакт **EternalHero-v0.20** из последней успешной [сборки GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml). Распакуй один раз в корень игры с заменой двух DLL. Второго ZIP внутри нет.
3. Запусти забег с Вечным защитником; уже купленные навыки и постоянные перки сохраняются.
4. Надень оружие с известным базовым уроном в **первый слот правой руки активного комплекта**. Открой «Картечь» и «Удар молнии»: их исходная сила должна рассчитываться от `Item.BaseDamages` этого оружия и штатных множителей каждого навыка.
5. Примени оба навыка по противнику. Изменение чисел в подсказке ещё не гарантирует, что реальная атака сработала.
6. Замени оружие на другое с иным уроном или переключи активный комплект: новый источник должен учитываться без перезапуска игры.
7. Сними оружие с первого слота — в дополнительных атакующих умениях должен использоваться резервный безоружный базовый диапазон 18–26 перед множителем.
8. Проверь, что кнопки «ВКЛЮЧИТЬ» / «ОТКЛЮЧИТЬ» в арсенале сохраняют покупки, а работающие постоянные таланты не изменились.

## Если урон всё ещё нулевой

Пришли `BepInEx/LogOutput.log` после открытия подсказки и применения обоих навыков. Полезные строки:

- `native item skill base damage adapter installed` — основной обработчик найден
- `combat + tooltip zero-damage fallback installed` — вторичный обработчик найден
- `first weapon slot` — мод прочитал реальный урон экипированного оружия
- `first weapon slot empty` — слот пустой или без положительного базового урона
- `zero damage repaired for` — исправлен нулевой диапазон

Проверка GitHub Actions подтверждает компиляцию и структурные тесты, **но не исполнение навыков внутри игры**.
