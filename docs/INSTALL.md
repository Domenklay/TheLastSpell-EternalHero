# Установка и тестирование Eternal Hero v0.3

1. BepInEx 5 x64 уже установлен — переустанавливать его не нужно.
2. На [странице сборок](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml) выбери последний успешный запуск.
3. Скачай артефакт EternalHero-prototype. Внутри архива находится EternalHero-prototype.zip. Распакуй ЕГО содержимое с заменой файлов в корневую папку The Last Spell.
4. Проверь два файла: BepInEx/plugins/EternalHero/EternalHero.Core.dll и EternalHero.Plugin.dll. Также появится папка BepInEx/plugins/EternalHero/ModKit с XML навыков.
5. Запусти игру. Справа вверху — кнопка Eternal Hero OPEN/CLOSE; другие способы: F8, F9 или Home.
6. В новом забеге после появления героев мод попробует определить первого персонажа, запомнить доступные поля внешности и выдаст единоразовый стартовый подарок: 100 метаопыта = 1 эссенция.
7. Пришли файл BepInEx/LogOutput.log после запуска НОВОГО ЗАБЕГА, а не только из главного меню. Нужны строки Eternal Hero appearance, Hero stat bridge, Hero ability bridge и Custom skills loaded from ModKit.

## Внешний вид

Окно перерисовано тёмными карточками и вкладками, с рамками и шкалой опыта. Загруженные в память игровые UI-спрайты переиспользуются, если удаётся распознать подходящую текстуру; иначе используется запасная тема. Игровые картинки не копируются в архив.

## Профиль

BepInEx/config/EternalHero/profile.json. Рядом создаётся профиль.bak — profile.json.bak — при последующих сохранениях.

## Подготовленные особые умения

Призрачный выстрел, Эфирный клинок и Пульс арканы представлены XML-определениями. Для их загрузки в базу игры нужен отдельный [TLS.ModKit](https://github.com/stunl0ck/tls-modkit). **Это пока не добавляет их герою на боевую панель.** Для привязки к ГГ нужно подтвердить API игры.

## Характеристики

Купленные ранги сохраняются в профиле, но их перенос на игровые характеристики пока тестовый. По умолчанию BepInEx/config/domenklay.tls.eternalhero.cfg — ApplyStatBonuses = false. Не включай в основном сохранении, пока мы не проверим совместимость с текущей версией игры.

Проверь лог. При любых сбоях пришли его вместе со скриншотом героя после начала нового забега.
