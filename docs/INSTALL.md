# Eternal Hero v0.15 — установка и тест

Перед обновлением создай резервную копию сохранений The Last Spell и `BepInEx/config/EternalHero/profile.json`.

1. Скачай артефакт **EternalHero-v0.15** из [последней успешной сборки](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml). GitHub отдаёт **один ZIP**. Внутри сразу `BepInEx/` и `INSTALL.md`. Распакуй в корень игры с заменой.
2. Если обновляешься с v0.14 или более ранней версии, удали **старую папку наших XML**: `BepInEx/plugins/EternalHero/ModKit/Skills/` — больше не нужна. Другие моды и их папки не трогай. TLS.ModKit для нашего арсенала не нужен.
3. Загрузи забег с Вечным защитником. Перейди во вкладку **Техники**. Она теперь открывает **Арсенал героя** с поиском, категориями и списком настоящих игровых навыков из оружия и украшений.
4. Выбери, например, доступный атакующий навык из «Магия» или «Стрельба». Нажми **КУПИТЬ • 4**. Вкладка покажет, сколько навыков куплено и сколько фактически выдано герою. Персонаж должен использовать умение без необходимого оружия, не расходуя ячеек сумки.
5. Закрой меню, выдели героя, проверь его **штатную панель умений**. Купленная способность должна появиться без нового предмета. После нового забега покупка не сбрасывается.
6. Если способности не видны, нажми **ПЕРЕПРОВЕРИТЬ** внизу вкладки и открой игру заново. В журнале `BepInEx/LogOutput.log` должны появиться сообщения `Eternal Hero stock native skill granted` или причина сбоя `Stock skill`.
7. За ранее купленные и не работавшие «Призрачный выстрел», «Эфирный клинок», «Пульс арканы», «Эхо охотника» и другие базовые экспериментальные техники один раз возвращается **по 5 эссенций за узел**. Старые ранги остаются в профиле и не покупаются повторно.
8. Для проверки постоянных перков зайди **Черты → Перки → Постоянные** и наведи курсор на «Точные удары». Внизу должен появиться статус «ВЫДАН» либо конкретная ошибка после попытки активации. В разделе «Сведения» остаётся общий счётчик выданных перков.

**Ограничение:** штатное умение из оружия может содержать дополнительные игровые условия по цели, атаке или предмету. Компиляция доказывает, что сборка создана; фактическое применение следует проверить на персонаже. Если навык есть в списке NativeSkills, но недоступен в бою, пришли название, скрин и журнал — нужно разбирать именно условия этого умения.

В игре оригинальное случайное дерево не обязано показывать дополнительно выданные перки или навыки. Следи за статусом в нашем меню и реальным эффектом в бою.
