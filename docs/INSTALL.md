# Установка прототипа v0.1

**Это технический прототип**, а не завершённая игровая модификация. Сначала сделайте резервные копии сохранений The Last Spell.

1. Установите **BepInEx 5 x64** в корневую папку The Last Spell. Один раз запустите игру, чтобы появилась папка BepInEx.
2. На странице репозитория **Actions → Build Eternal Hero prototype** откройте успешную сборку и скачайте артефакт **EternalHero-prototype**.
3. Внутри артефакта находится \`EternalHero-prototype.zip\`. Распакуйте его содержимое в папку игры так, чтобы получилось:
   - \`The Last Spell/BepInEx/plugins/EternalHero/EternalHero.Plugin.dll\`
   - \`The Last Spell/BepInEx/plugins/EternalHero/EternalHero.Core.dll\`
4. Запустите игру и нажмите **F8**. Появится окно метапрогрессии.
5. В логах \`BepInEx/LogOutput.log\` найдите строки \`Eternal Hero\` и \`Patched PlayableUnitManager.CreateStartUnits\`.
6. Начните **новую** игру, убедитесь, что стартовый ростер работает и в логе отражено определение кандидата на ГГ.

## Где хранится профиль
\`BepInEx/config/EternalHero/profile.json\`; резервная копия — \`profile.json.bak\`.

## Тестовое начисление опыта
После первого запуска поменяйте \`EnableTestRewards = false\` на \`true\` в конфиге
\`BepInEx/config/domenklay.tls.eternalhero.cfg\`. Перезапустите игру и используйте кнопку **DEV: +100 опыта** в F8. Это временный тестовый способ, а не рабочее получение опыта от боёв.

## Ограничения прототипа
- Стартовый персонаж: обнаружение через рефлексию, без гарантии, что нашли правильный объект в конкретном билде игры.
- Смена имени: попытка через известные поля, может не сработать.
- Статы: по умолчанию **не применяются к игре**. Экспериментальный мост включается только через \`ApplyStatBonuses = true\` на свой риск; его ещё предстоит проверить, и возможны повторные прибавки на загрузке сохранения.
- Специальные оружейно-независимые приёмы, постоянные черты, автоматическое начисление опыта за ночи, распознавание побед/поражений пока находятся в разработке.
- Никаких копий игровых DLL в репозитории не должно быть.

## Как собрать самостоятельно
Установить .NET SDK 8; в корне проекта:
\`dotnet run --project tests/EternalHero.Tests/EternalHero.Tests.csproj -c Release\`
\`dotnet build src/EternalHero.Plugin/EternalHero.Plugin.csproj -c Release\`

Используются общедоступные зависимости NuGet (BepInEx, HarmonyX, UnityEngine.Modules).
