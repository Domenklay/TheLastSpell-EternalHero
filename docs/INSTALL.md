# Eternal Hero v0.22 — установка и проверка

1. Сохрани копию игровых сохранений и `BepInEx/config/EternalHero/profile.json`.
2. Скачай ZIP-артефакт **EternalHero-v0.22** из последней успешной [сборки GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml). Распакуй один раз в корень игры с заменой двух DLL. Второго ZIP внутри нет.
3. Запусти забег с Вечным защитником; уже купленные навыки и постоянные перки сохраняются. В меню F8 статус боевых обработчиков должен показывать `BaseDamage=OK, диапазон=OK` (если один недоступен, второй устанавливается независимо).
4. Надень оружие с известным базовым уроном в **первый слот правой руки активного комплекта**. Открой «Картечь» и «Удар молнии». Для **купленных атакующих навыков** теперь действует минимальный базовый диапазон 125% от `Item.BaseDamages`, даже если исходный коэффициент навыка ниже. Например, при 176–224 базовая планка 220–280 (до других боевых модификаторов). Сильные исходные умения не ослабляются.
5. Примени оба навыка по противнику. Изменение чисел в подсказке ещё не гарантирует, что реальная атака сработала.
6. Замени оружие на другое с иным уроном или переключи активный комплект: новый источник должен учитываться без перезапуска игры.
7. Сними оружие с первого слота — при отсутствии оружия используется резервный диапазон 18–26, с минимальным коэффициентом 125% это 23–33. Низкие значения вроде 16–22 при хорошем оружии могут указывать на пустой первый слот **активного** комплекта; проверь, какой комплект выбран.
8. При необходимости настрой `BepInEx/config/domenklay.tls.eternalhero.cfg`: параметр `PurchasedAttackDamageFloorPercent = 125` (100 = минимум 100% урона оружия, 200 = минимум 200%, 0 отключает минимальный урон). После изменения перезапусти игру.
9. Проверь, что навыки помощи с нулевым коэффициентом урона не получили атаку, а другие герои не изменились.
10. Проверь, что кнопки «ВКЛЮЧИТЬ» / «ОТКЛЮЧИТЬ» в арсенале сохраняют покупки, а работающие постоянные таланты не изменились.

## Если урон всё ещё слишком мал или нулевой

Пришли `BepInEx/LogOutput.log` после открытия подсказки и применения обоих навыков. Полезные строки:

- `native item skill base damage adapter installed` — основной обработчик найден
- `damage hooks: BaseDamage=..., ComputeBaseDamageRange=...` — фактически установленные перехваты
- `combat + tooltip purchased-attack damage floor installed` — обработчик минимального урона найден
- `first weapon slot` — мод прочитал реальный урон экипированного оружия
- `first weapon slot empty` — слот пустой или без положительного базового урона
- `purchased attack floor applied to` — слабый или нулевой диапазон поднят до минимума

Проверка GitHub Actions подтверждает компиляцию и структурные тесты, **но не исполнение навыков внутри игры**.
