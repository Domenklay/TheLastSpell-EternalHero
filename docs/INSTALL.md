# Eternal Hero v0.4 — установка и проверка

**Перед тестом сделай резервную копию сохранений The Last Spell.** Это крупное обновление: Unity Canvas вместо прежнего окна IMGUI и изменения первого персонажа команды.

1. Оставь установленный **BepInEx 5 x64**, который уже успешно запускал наш мод.
2. Открой [GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml), выбери последний **зелёный** запуск, скачай артефакт `EternalHero-prototype`.
3. Из загруженного ZIP распакуй **внутренний** `EternalHero-prototype.zip` в папку The Last Spell с заменой файлов.
4. Убедись, что в `BepInEx/plugins/EternalHero/` лежат `EternalHero.Plugin.dll`, `EternalHero.Core.dll` и папка `ModKit/Skills`.
5. Запусти игру. Появится **новый экран Unity UI** «Вечный защитник», а не старое полупрозрачное меню. Открывается F8/F9/Home или кнопкой справа вверху.
6. На вкладке «Герой» введи имя, выбери расу и пол, нажми «Сохранить героя».
7. На вкладке «Черты» выбери **одну игровую черту** (ещё слоты можно разблокировать в ветке «Наследие»).
8. На вкладке «Развитие» уже должно быть **одно очко эссенции** для тестовой покупки таланта. Оно выдаётся раз на профиль; старые подарки не удваиваются.
9. Закрой экран мода и **начни новый забег**. Мод попытается изменить первого героя команды.
10. Нажми «Редактор внешности»: откроется штатный редактор The Last Spell — с настоящими игровыми лицами, прическами, цветами и портретами. После подтверждения мод запоминает код портрета и имя.
11. Проверь имя/расу/черту в характеристиках первого героя и эффект купленной характеристики.
12. После пережитой ночи проверь увеличение «Постоянного опыта» — выдается по игровому вызову начисления опыта за ночь.

## Особые техники

Для регистрации трёх `ModKit/Skills/*.patch.xml` нужен установленный [TLS.ModKit](https://github.com/stunl0ck/tls-modkit). Сами определения входят в ZIP. Выданные способности должны появляться как собственные навыки героя после их покупки. Это ещё нужно проверить в игре; при несовместимом API смотри лог.

## Логи

Нужен **новый** файл `BepInEx/LogOutput.log` после **нового забега**, а не из главного меню. Ищи `Eternal Hero v0.4.0`, `native Canvas initialized`, `first unit discovered`, `applied profile`, `stat upgrades`, `active skills`, `rewarded survived night`.

Если экран не открылся или игра упала, пришли лог; оригинальный файл сохранения не удаляй.

## Хранение профиля

`BepInEx/config/EternalHero/profile.json`, запасная копия — `profile.json.bak`.

Для временного отключения характеристик открой `BepInEx/config/domenklay.tls.eternalhero.cfg` и установи `ApplyVerifiedStatBonuses = false`, затем перезапусти игру.
