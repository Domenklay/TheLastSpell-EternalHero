# Eternal Hero v0.20 — установка и проверка
## Обновление v0.20 — базовый урон первого оружейного слота
1. Сохрани копию профиля и игровых сохранений.
2. Скачай **EternalHero-v0.20** с последнего успешного запуска GitHub Actions, распакуй **один раз** в корень The Last Spell с заменой двух DLL.
3. Надень оружие с известным базовым уроном в **первый слот правой руки активного комплекта**.
4. Проверь подсказки «Картечь» и «Удар молнии», а затем фактический урон по врагу. База обеих атак должна соответствовать текущему оружию, после неё применяются индивидуальные множители.
5. Замени оружие на более сильное или переключи комплект: новые значения должны учитываться без перезагрузки.
6. Сними оружие из первого слота: должна действовать резервная безоружная база 18–26.
7. Если всё ещё ноль, отправь `BepInEx/LogOutput.log`. Важные строки: `first weapon slot`, `first weapon slot empty`, `zero damage repaired for`, `combat + tooltip zero-damage fallback installed`.
Сборка GitHub подтверждает компиляцию и структурные тесты, но не реальную атаку в игре.


1. Сделай резервную копию игровых сохранений и `BepInEx/config/EternalHero/profile.json`.
2. Скачай **EternalHero-v0.19** из последней успешной [GitHub Actions-сборки](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml). Распакуй **один ZIP** в корень The Last Spell с заменой двух DLL; внутри нет второго архива.
3. Запусти забег с уже созданным Вечным защитником. **Не покупай навыки повторно**: прежние покупки сохранены.
4. Выбери изученную «Картечь» без оружия: вместо `Урон: 0` в подсказке должен быть положительный базовый урон с последующим множителем навыка. Используй способность по врагу.
5. Отдельно проверь «Удар молнии» без оружия: должно появиться ненулевое значение и реальный урон.
6. В меню «Техники» выключи любую купленную способность, убедись, что она скрыта, затем включи обратно. Ранее установленная работоспособность постоянных перков должна сохраниться.

### Если по-прежнему 0

Пришли `BepInEx/LogOutput.log` **после открытия подсказок обеих атак** и фото экрана. В журнале ищи:
- `native item skill base damage adapter installed` — основной перехват установлен
- `combat + tooltip zero-damage fallback installed` — второй перехват установлен
- `source weapon base damage` — конкретный исходный диапазон найден
- `no positive original item base damage` — у предметов не было положительного диапазона
- `zero damage repaired for` — второй перехват исправил нулевой результат

Если ни одна из строк не появляется, нужно проверить загрузку `EternalHero.Plugin.dll` и отсутствие старой копии. Если оба обработчика установлены, но урон всё ещё 0, именно лог поможет определить, почему не совпадает владелец или ID конкретной атаки.

Компиляция прошла, однако поведение в установленной игре не проверено автоматически.
