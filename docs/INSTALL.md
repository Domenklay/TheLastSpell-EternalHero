# Вечный защитник v0.6 — установка и проверка

Перед установкой скопируй свои сохранения игры и профиль мода `BepInEx/config/EternalHero/profile.json` в безопасное место.

1. Установленный BepInEx 5 оставь как есть.
2. На [странице GitHub Actions](https://github.com/Domenklay/TheLastSpell-EternalHero/actions/workflows/build.yml) открой последний **успешный** запуск и скачай артефакт **EternalHero-v0.6**. Внешний архив содержит внутренний `EternalHero-v0.6.zip`.
3. Распакуй содержимое внутреннего архива в **корень The Last Spell** и замени старые DLL.
4. Убедись, что нет второй копии `EternalHero.Plugin.dll` в другой подпапке `BepInEx/plugins/`.
5. Запусти игру: теперь меню не открывается автоматически. Чтобы открыть его, нажми **F8**, **F9** или **Home**. Также есть маленькая кнопка **✦** у **правого края по центру экрана**, а не поверх трёх портретов героев.
6. Меню должно занимать значительно меньше места (78% прежнего масштаба). Можно открыть вкладку «Герой», проверить имя, расу, пол и код портрета, затем «Сохранить героя».
7. Зайди в текущий сохранённый забег. Мод теперь **не только находит**, но и **пытается применить** имя, расу, внешность и выбранные черты к **первому** члену стартовой команды. Это не четвёртый персонаж.
8. Проверь имя первого героя в интерфейсе команды, его внешность, расу и выбранные черты. Обязательно попробуй закрыть и снова загрузить сохранение. Проверь, не удвоились ли бонусы характеристик.
9. Начни **новый забег** и проверь ту же последовательность. Для теста рекомендуется отдельное сохранение: изменение расы уже существующего героя — сложная операция.
10. При проблемах пришли `BepInEx/LogOutput.log` после загрузки забега, а также скриншот панели с именами всех трёх персонажей.

## Что исправлено технически

В предыдущих версиях существовал отдельный путь для загрузки сохранения: он находил героя, **но не применял** сохранённые данные внешности, имени и черт. Теперь вызывается та же процедура профиля, что и на новом забеге, с дополнительным обновлением игровых портретов и имени в HUD. Повторное прибавление уже сохранённых базовых статов запрещено.

**Важно:** автоматическое восстановление настоящего рисунка по коду портрета, обновление расовых бонусов и черт могут зависеть от версии игры. Компиляция подтверждает корректность DLL, а фактическое отображение проверяется только в The Last Spell.

## Настройки

`BepInEx/config/domenklay.tls.eternalhero.cfg`
- `OpenCreatorOnStartupV06 = false` — по умолчанию не перекрывать игру меню при запуске.
- `ApplyVerifiedStatBonuses = true` — применять бонусы только по доступному игровому API.
- `EnableTestRewards = false` — тестовые очки скрыты, включаются вручную.

Прогресс v0.5 (96 улучшений, Возвышение, выбранные черты и перки) сохраняется.
