# Eternal Hero — v0.9

## Реализовано в коде
- [x] Библиотека **всех** игровых PerkDefinition из базы The Last Spell
- [x] Отдельные режимы выбора: постоянные перки и покупки за обычные очки забега
- [x] Поддержка изучения перков, отсутствующих в исходных 6 колонках героя
- [x] Использование штатного PerkController; проверка активации до списания игрового очка
- [x] Защита от повторного изучения уже открытых перков
- [x] Перки забега создаются как dynamic perks, поддерживаемые сериализацией игры
- [x] Сортировка по оригинальной специализации и уровню из UnitPerkCollectionDefinitions
- [x] Оригинальные игровые иконки рядом с названием перка
- [x] Восемь рангов «Наследника знаний» → до +8 очков перков в каждом забеге
- [x] Учёт уже начисленных метаочков после загрузки сохранения, выдача только разницы при покупке
- [x] Исправлена активация выбранных постоянных перков, уже существующих в списке, но заблокированных
- [x] Вся метапрогрессия v0.8 и сохранения профиля совместимы

## Проверить в запущенной игре
- [ ] Можно ли купить перк, которого нет в 6 штатных колонках, за 1 реальное очко
- [ ] После покупки активируется ли его эффект и уменьшается ли PerksPoints точно на 1
- [ ] Перк остаётся в игровом сохранении после закрытия/загрузки и пропадает в новом забеге
- [ ] Не дублируются ли очки «Наследника знаний» при повторной загрузке
- [ ] Сохранённый постоянный перк выдаётся бесплатно в новых забегах
- [ ] Каталог отображает корректные оригинальные иконки, категории и уровни
- [ ] Остальные герои не получают никакие изменения
