# Eternal Hero — roadmap после v0.10

## Переработка UI
- [x] Убрана пагинация каталога черт и перков
- [x] Четыре колонки с непрерывной прокруткой
- [x] Создание лишь видимых карточек (виртуализация)
- [x] Поиск по нескольким словам без Enter
- [x] Категории по игровым статам, многокатегорийные черты
- [x] Фильтры отрицательных эффектов, выбранных, подходящих по расе
- [x] Выбранный набор закреплён под портретом с быстрым переходом
- [x] Полное описание черт из игрового GetDescription(), окно с прокруткой
- [x] Позиция просмотра сохраняется при выборе/удалении черты
- [x] Сохранена вся метапрокачка и профиль из предыдущих версий
- [x] CI проверяет классификацию, поиск, сборку DLL и XML

## Проверить на установленной игре
- [ ] Каталог не тормозит при большом количестве модовых черт
- [ ] Клик по «?» не выбирает черту, пока открывает описание
- [ ] Условные игровые эффекты и все локализованные строки отображаются правильно
- [ ] Выбор черт не сбрасывает текущую прокрутку
- [ ] Проверить меню в 1366×768 и 1920×1080, в том числе на MenuScale=0.68/0.78
- [ ] Проверить, что постоянные и разовые перки по-прежнему выбираются без ошибок
- [ ] Проверить, что после нового забега выбранные черты не теряются

## Следующее направление
- [ ] Проверка настоящих боевых эффектов «Последний бастион», телепортации, эх
- [ ] Доработка сохранения и активации нестандартных перков на реальном билде The Last Spell
- [ ] Выдача наград за победы, поражения и боссов
- [ ] Оптимизация и дополнительные стилистические элементы на основании скриншотов из игры

Контроль качества: GitHub Actions — только проверка сборки, тестов логики и XML. Нужен реальный запуск The Last Spell для проверки интерфейса.
