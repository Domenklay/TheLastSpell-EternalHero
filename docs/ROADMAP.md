# Eternal Hero v0.18 — контроль

## Реализовано в исходниках
- [x] Подмена нулевого базового урона купленных оружейных навыков настоящими значениями из исходных предметов
- [x] Ограничение Harmony-патча только одним купившим и включившим умение ГГ
- [x] Вычисление финального урона оставлено исходному боевому движку
- [x] Адаптивный поиск конструкторов PerkController с поддержкой разных сигнатур и непубличных конструкторов
- [x] Использование типа контроллера уже работающих перков героя как приоритетного источника
- [x] Регистрация перка и его разблокировка через игровые API, диагностика ошибок
- [x] Автоматические проверки сборки DLL и статической интеграции
- [x] Один ZIP без вложенных архивов, прежний профиль не удаляется

## Проверить непосредственно в The Last Spell
- [ ] «Картечь» и другие купленные оружейные навыки имеют ненулевой урон
- [ ] Реальные атаки наносят урон, корректно действуют мультипликаторы и эффекты
- [ ] Отключение навыка не затрагивает его покупку и обычное оружие
- [ ] «Точные удары» и «Любовь к обучению» выдаются вне случайных колонок и реально работают
- [ ] Уже работающие «Сборщик маны» и другие перки не перестают работать
- [ ] Сохранения, переключатели, валюты, характеристики и бонусы других персонажей не меняются

Если клиент не поддерживает создание PerkController даже после поиска сигнатуры, нужен лог с перечислением реальных конструкторов этой версии игры — без него утверждать, что именно не совпало, нельзя.
