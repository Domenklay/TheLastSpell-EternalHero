# Eternal Hero v0.5 — roadmap

## Реализовано в исходниках / покрыто тестами
- [x] 96 узлов, шесть веток, сохранение старых ID v0.4
- [x] Метаранг 1–100 от доли купленных рангов
- [x] Проверка полного дерева и автоматическое открытие Возвышения
- [x] Шесть бесконечно повторяемых статовых Возвышений с ростом стоимости
- [x] Отдельный интерфейс веток, вкладка Возвышения, прогресс ранга
- [x] Выбор черт и существующих перков с поиском, 12 результатов на страницу
- [x] Восемь слотов постоянных перков; native PerkController attempts to grant
- [x] XML трёх старых специальных навыков и трёх новых дополнительных ударов без AP
- [x] Привязка трёх новых навыков к NativeSkills при выполнении условий
- [x] Защита от повторного применения статов при загрузке сохранения
- [x] Профиль, прогресс, выбранные перки и Возвышение переживают перезапуск
- [x] GitHub CI: сборка, тесты системы развития, XML syntax check

## Требуется игровой тест
- [ ] Проверить все 6 навыков через реальный TLS.ModKit и панель NativeSkills
- [ ] Проверить выдачу выбранных постоянных перков через PerkController
- [ ] Проверить первые 3 эха/дополнительные выстрелы в настоящем бою
- [ ] Проверить применение игровых статов и их сохранение без дублирования при переходах
- [ ] Проверить прокачку 1–100 в UI на разных размерах экрана
- [ ] Проверить создание персонажа с сохранённой внешностью и расой

## Пока не реализовано
- [ ] Персонаж создаёт две настоящие призрачные анимации; сейчас эха только скиллы, а не отдельные призрачные модели
- [ ] Боевое «Последний бастион»: один раз за ночь переживает смертельный урон
- [ ] Активная телепортация
- [ ] Автоповтор выстрела по второй цели; сейчас отдельный навык с 0 AP
- [ ] Разные особенности умений на каждом уровне мастерства (сейчас пассивные бонусы)
- [ ] Выдача наград за победы, поражения, боссов через реальные игровые события
- [ ] Полностью идентичное оформление UI со всеми игровыми UI-панелями
- [ ] Боевой бенчмарк: эквивалентность трём хорошо развитым персонажам

Для следующего шага нужен новый BepInEx/LogOutput.log из запущенного боя с TLS.ModKit и скриншот меню ГГ.
