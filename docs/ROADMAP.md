# Eternal Hero — состояние v0.6

## Изменено
- [x] Модальное окно уменьшено на 22%, интерфейс по-прежнему на Unity UGUI
- [x] Кнопка ✦ перенесена с верхнего правого HUD на правый край в центр
- [x] Открытие меню при запуске отключено по умолчанию
- [x] На загрузке сохранения, помимо обнаружения первого героя, теперь применяется выбранная идентичность ГГ
- [x] Создание новой команды больше не блокирует применение профиля из-за CreationConfirmed=false
- [x] Попытка обновить текст имён, модель персонажа и портреты в игровом HUD
- [x] Дополнительная проверка списка персонажей при пропущенном событии загрузки
- [x] Сохранение прежних метаулучшений и защита от повторного начисления статов

## Проверить в реальной игре
- [ ] Меняется ли имя первого персонажа в интерфейсе команды при загрузке существующего сохранения
- [ ] Совпадают ли портрет, лицо, волосы, выбранная раса и игровой спрайт с сохранёнными настройками
- [ ] Применяются ли черты и постоянные перки и не дублируются ли после загрузки
- [ ] Масштаб и читаемость компактного окна на разных разрешениях
- [ ] Не перекрывает ли кнопка ✦ другие элементы HUD при игре
- [ ] Продолжает ли главной герой появляться первым при следующем новом забеге

## Крупные игровые механики, которые ещё не гарантированы
- Настоящее сохранение портретного кода во всех билдах и обновление каждого элемента HUD
- Безопасная синхронизация расовых бонусов без побочных эффектов
- Точное восстановление внешности после сериализации с нестандартными сборками игры
- Боевая реализация пассивного «Последнего бастиона», телепортации, автоматических выстрелов эх
- Начисление наград за все игровые события и испытания на эквивалент трёх героев

Сборка и тесты в GitHub Actions проверяют только код и данные, но не реальное поведение игры.
