## Проверить в игре
- [ ] Описание всплывает при наведении без клика.
- [ ] Все 16 XML определений приняты TLS.ModKit.
- [ ] Изученные навыки появляются на боевой панели и действительно действуют.
- [ ] Варианты навыков заменяются при 3/5 рангах, а не дублируются.
- [ ] Эха атакуют за 0 AP и 0 маны, один раз за ход.
- [ ] Эфирный шаг перемещает на допустимую клетку, без оружия.
- [ ] Последний бастион действительно спасает от смерти ночью и не влияет на остальных героев.
- [ ] Победа, поражение и боссовая фаза дают награду только один раз.
- [ ] Старый профиль получил компенсацию, новый не получает её без оснований.
- [ ] Сохранённые имя, портрет, черты и личные достижения остаются на месте.
