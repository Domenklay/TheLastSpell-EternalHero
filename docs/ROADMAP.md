# Eternal Hero v0.15 — статус

## Реализовано
- [x] Весь каталог навыков формируется по данным **оригинального оружия и украшений** игры.
- [x] Поиск и фильтры по типу предметов, собственная покупка за эссенцию.
- [x] Навыки сохраняются в профиле, выдаются напрямую герою без предметов и слотов.
- [x] Старые экспериментальные XML больше не упаковываются в мод; удалена зависимость от TLS.ModKit.
- [x] При переходе со старой версии один раз возвращается эссенция за неработавшие базовые техники.
- [x] При загрузке и выборе героя проверяется наличие выданных NativeSkills.
- [x] Ошибки выдачи постоянных перков выводятся в журнал и статус карточки.
- [x] Новые тесты покупки оригинальных навыков и защиты от двойного возврата.

## Проверить в установленной игре
- [ ] База предметов доступна в каталоге и количество навыков больше нуля.
- [ ] Купленный навык появляется в NativeSkills, отображается на панели и действует без предмета.
- [ ] Разные категории навыков не конфликтуют при одновременном использовании.
- [ ] Оружейные умения, зависящие от атрибутов оригинального предмета, действительно работают без него.
- [ ] Покупки сохраняются после закрытия и повторного запуска игры.
- [ ] «Точные удары» доступны вне случайного дерева либо показывают конкретную причину отказа.
- [ ] Остальные перки, расовые модификаторы и обычная экипировка не сломались.
