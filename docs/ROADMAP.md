## Проверить в игре
- [ ] Картечь: подсказка показывает урон больше нуля, навык действительно атакует
- [ ] Удар молнии: подсказка показывает урон больше нуля, навык действительно атакует
- [ ] Множители навыка (например, 75%) применяются к исходному значению
- [ ] Остальные купленные навыки используют оригинальные/резервные значения без предметов
- [ ] Работающие постоянные перки не перестали действовать
- [ ] Сторонние герои, обычное оружие и вспомогательные навыки не изменились
- [ ] Переключение навыков и сохранение профиля работают как раньше

Без теста в самой The Last Spell нельзя утверждать, что боевое исполнение исправлено; CI проверяет только сборку, структуру и тесты ядра.
