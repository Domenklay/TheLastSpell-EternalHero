# Eternal Hero v0.7 — состояние реализации

## Изменено
- [x] Сохранение кода портрета при подтверждении в оригинальном редакторе
- [x] Защита от удаления кода при повторном выборе текущего пола
- [x] Попытка переноса изображения и модели через код, цветовую палитру, снимок и обновление игрового HUD
- [x] Выбранные постоянные черты принудительно добавляются при конфликтах со случайными чертами и отображаются первыми
- [x] Неограниченный выбор обычных перков из каталога (без ограничения на тип оружия)
- [x] Попытка открыть все уровни штатного дерева перков только у ГГ
- [x] Сохранение личной статистики LifetimeStats через max-merge, включая любимое оружие и вражеские типы
- [x] Восстановление накопленных личных достижений при новом забеге, автосохранение каждые 15 секунд
- [x] Сохранены 96 узлов метапрогрессии, Возвышение, шестью дополнительными навыками

## Проверить в реальной игре
- [ ] На новом забеге появляется сохранённый код портрета и точная копия внешности
- [ ] Выбранная черта отображается первой и меняет соответствующую характеристику
- [ ] Все уровни штатного дерева перков открыты именно у ГГ
- [ ] Любой выбранный постоянный перк создаётся и разблокируется без дублей
- [ ] Киллы, урон, лучший удар и любимое оружие переходят из предыдущего забега в следующий
- [ ] При повторной загрузке и продолжении сохранённого забега статистика не удваивается
- [ ] Достижения и выбранные черты не влияют на остальных героев

## Отдельные будущие задачи

- Автоматические награды за финального босса, победы и поражения
