# Eternal Hero v0.8 — техническое состояние

## Реализовано в моде
- [x] Компактный каталог черт и перков: 4 столбца, 5 строк на страницу
- [x] Поиск по ID/названию/эффекту, фильтры негативных и выбранных черт
- [x] До 12 дополнительно выбираемых постоянных черт (11 рангов legacy.trait)
- [x] Добавленные черты располагаются первыми в игровом списке
- [x] Режим подавления отрицательных расовых модификаторов и двух типов условных расовых эффектов
- [x] Положительные расовые модификаторы не изменяются
- [x] Отдельная настройка выключения подавления штрафов
- [x] Патч геттера доступности UnitPerkTier исключительно для ГГ
- [x] Периодическая синхронизация открытия всех рангов штатного дерева при его появлении
- [x] Сохранение предыдущей v0.7 прокачки, профиля и достижений

## Требуется тест в игре
- [ ] Урон с расовым штрафом на пустоши и без него: проверка, что отрицательное значение не влияет на бой
- [ ] Положительные расовые бонусы в лесу не исчезли
- [ ] Все уровни II–V действительно активны для ГГ, а прочие герои не затронуты
- [ ] До 12 дополнительных черт дают правильные статовые эффекты и сохраняются между забегами
- [ ] Проверить каталог и 4 колонки на разных разрешениях
- [ ] Фильтры «Без штрафов» / «Со штрафами» соответствуют реальным дефинициям черт

## Ограничения
- [ ] Исходные тексты расовых подсказок всё ещё могут показывать штрафы даже после отключения их эффектов
- [ ] В штатной карточке The Last Spell число видимых иконок черт ограничено; все выбранные черты видны в меню мода
- [ ] Расширение числа `native` специализаций в оригинальном дереве сверх случайно назначенных колонок — отдельная задача
- [ ] Полноценная автоматизация двух боевых эх, телепортации и «Последнего бастиона» — отдельная задача
